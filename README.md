## 📌 Project Overview
**Learn IQ** is an adaptive AI Career Navigator designed specifically for 1st and 2nd Year B.Tech Computer Science & Engineering (CSE) students. It bridges core academic coursework (C Programming, Data Structures, DBMS, Operating Systems, DAA) with real-world industry job expectations (SDE-1, Backend Systems Engineer, AI/ML Specialist).

Using documented **SFIA** (Skills Framework for the Information Age) and **O*NET** taxonomy alignment, it calculates priority skill gaps, builds staged project roadmaps, and dynamically adjusts timelines based on students' available weekly study hours.

---

## ✨ Key Features
- **Academic-to-Industry Skill Mapping:** Tailored for 1st & 2nd-year CSE engineering subjects.
- **Dynamic Time Recalibration:** Interactive slider (5–30 hrs/week) that updates estimated milestone durations in real time.
- **Embedded Response Hub:** Integrated Google Form response collector directly embedded into the web app.
- **Dashboard & Analytics:** Local storage logging for candidate submissions, radar gap charts, and readiness scores.
- **Ethical Safeguards:** Full compliance with hackathon safety boundaries (non-employment guarantees and non-judgmental skill assessments).

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+)
- **Data Persistence:** Browser LocalStorage API + Embedded Google Form
- **Visualization:** Chart.js Radar Skill Gap Matrix
